## 保留内容与重排方法

原 20 个场景及各自的 Chemistry、评估种子、10 个 Trial 的潜在/可见初始石头、预期价值/转移表、Oracle 分数全部保留。没有重新抽样、重新生成 Trial 或改变奖励。每类仍有 5 个 Episode；每类和总体逐 Trial Oracle 均分仍为 42.2；没有初始即 45 分的 Trial。

直接按原类型内顺序交错会有相邻映射/反射重复。因此在类型位置固定的前提下，确定性搜索同类型 Episode 的排列，使相邻 potion_permutation、potion_reflections、stone_reflections 各自均不同。目标是在稳定交错顺序基础上最少移动位置，共 7 个；同目标解按原编号确定性优先。

原始 JS 和 CSV 已归档在 `docs/protocol_archive/oracle_balanced20_grouped/`；当前 CSV 给出新旧编号和 block 位置。重新生成命令：

```powershell
python tools/reorder_block_schedule.py
```

JSON 的 Trial、Episode、动作事件和 CSV 事件新增 `originalEpisode`、`block`、`positionInBlock`。JSON 元数据包含完整 ordering。新 scheduleId 自动隔离浏览器备份命名空间，旧版被试备份不会被新版本读取或覆盖。既有模型的评估输入及完成结果没有修改；比较旧模型结果时应按原 Episode 编号或 Chemistry ID + seed 对齐。

## 指导语

任务说明来自实验目录内的 `实验指导语.docx`，原 DOCX 未修改。其 27 个非空段落按原文顺序显示，包括标题、六节正文；没有保留旧说明的额外段落。源文件 SHA256 和提取文本保存在 `docs/instructions_source.json`。

说明框使用原有面板素材，标题与底部返回按钮固定，仅正文区域滚动。重新打开时正文回到顶部；返回和 Escape 均可关闭。验证尺寸包含 1366×768、1280×600 和 1920×1080。
