# Alchemy 2D v6.5：三块石头统一投入、含负分结算

当前程序仍位于原 `Alchemy2D_Web_v6_4_ButtonScorePatch` 文件夹，页面与导出版本为 `6.5.0-signed-batch`。

## 启动

双击 `index.html`；或双击 `启动网页版_Windows.bat`。本次已启动的本地预览为 http://127.0.0.1:8780/ 。整套程序离线可运行，无外部图片或字体服务。

## 当前规则

- 一个 Trial 三块石头、六色药水各两瓶。可先选择石头与药水并用药，也可直接点击「全部投入并结算」，不需要先选择石头。
- 该按钮一次结算全部三块石头，并立即结束当前 Trial。没有逐块投入或单独「结束本轮」按钮。
- 分数是三块石头当前分数的直接求和，**−3、−1 也计入**，不截为 0，不允许丢弃负分石头。例如 `+1 −3 −3 = −5`、`+15 −1 −3 = +11`。
- 石头左侧价值温度计：蓝色一格=−3，浅蓝两格=−1，浅橙三格=+1，橙色四格=+15。对应关系仅在「任务说明」中给出，石头操作界面不列出分值；药水颜色不是分值。
- 使用最后一瓶药水时立即自动结算。保留该次用药的前后反馈，点「继续」后自动展示合计数字，不再需要点击结算按钮。
- 三块石头同时飞入坩埚，随后只显示合计数字。数字直接从用户给定 `assets/ui/source_art/gothic_numeral_atlas.png` 组合，支持负数与多位数。原素材未改写。
- 完成数字展示后点击「进入下一 Trial / Episode」。开启减少动画偏好时，跳过飞行动画，保留静态合计数字。
- 「上一次用药」只显示最近一次的药水及石头用药前后变化；跨 Trial 保留，每个新 Episode 清空。完整用药事件仍保留在实验数据导出中。
- 桌面布局中，该横条仅占左侧石头栏与中间操作台的宽度；右侧药水栏向下延伸，与横条底部对齐。较高窗口中，石头区、操作台及药水区随可用高度增高，底部保留约 24px 留白；较矮窗口保持紧凑。结算不显示逐块分数求和文字。
- 每个 Episode 内 Chemistry 不变，既有 Episode 非重复采样及药水布局方式保持不变。

## 数据与恢复

JSON/CSV 使用新版本和新的浏览器会话键 `alchemy_human_experiment_v6_5_signed_batch_session`，不覆盖旧版会话键。旧版备份不会自动混入新规则。

每轮分数、三块石头各自分数、用药数、原始总价值增量及统一投入事件均记录。结算在动画之前持久化；重复点击、动画中刷新、最后药水反馈中刷新均不会再次加分。未完成时保留本地恢复备份，完成后请下载实验数据。

修改前完整项目已另存于父目录 `_backups/game_before_all_stones_signed_20261024_003511.zip`，详见 `v6.5_修改与核验说明.md`。旧 v6.3 Word 手册和旧版本修改说明保留作历史参考，操作以本 README 和游戏内说明为准。
