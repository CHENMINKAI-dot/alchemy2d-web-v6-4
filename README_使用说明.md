# Alchemy 2D v6.6：固定验证集 20 × 10 人类实验

当前程序仍位于原 `Alchemy2D_Web_v6_4_ButtonScorePatch` 文件夹，页面与导出版本为 `6.6.0-fixed-eval20`。

## 启动

双击 `index.html`；或双击 `启动网页版_Windows.bat`。本次已启动的本地预览为 http://127.0.0.1:8780/ 。整套程序离线可运行，无外部图片或字体服务。

## 固定实验安排

封面使用用户提供的炼金图，只显示「开始实验」和「关于实验」两个按钮。「开始实验」打开模式弹窗；练习模式直接进入 2 个 Trial，无需编号；实验模式先输入被试编号（可按 Enter 确认），再开始正式实验。「关于实验」打开游戏规则，运行中不显示说明按钮。

正式实验固定为 20 个 Episode、每个 10 个 Trial、seed=0。按 0/1/2/3 个前置约束各 5 个，从原 6,278 个验证场景固定抽取；保留原验证种子和全部 Trial 初始条件。相邻药水轴映射、药水方向反射和石头外观反射均不同，全程无重复 Chemistry。

详细算法与编码说明见 `v6.6_固定验证场景说明.md`，研究者场景表见 `固定实验场景清单.csv`。练习仍独立运行 2 个 Trial。

## 当前规则

- 一个 Trial 三块石头、六色药水各两瓶。可先选择石头与药水并用药，也可直接点击「全部投入并结算」，不需要先选择石头。
- 该按钮一次结算全部三块石头，并立即结束当前 Trial。没有逐块投入或单独「结束本轮」按钮。
- 分数是三块石头当前分数的直接求和，**−3、−1 也计入**，不截为 0，不允许丢弃负分石头。例如 `+1 −3 −3 = −5`、`+15 −1 −3 = +11`。
- 石头左侧价值温度计：蓝色一格=−3，浅蓝两格=−1，浅橙三格=+1，橙色四格=+15。对应关系仅在「任务说明」中给出，石头操作界面不列出分值；药水颜色不是分值。
- 使用最后一瓶药水时立即自动结算。保留该次用药的前后反馈，点「继续」后自动展示合计数字，不再需要点击结算按钮。
- 三块石头同时飞入坩埚，随后只显示合计数字。数字直接从用户给定 `assets/ui/source_art/gothic_numeral_atlas.png` 组合，支持负数与多位数。原素材未改写。
- 完成数字展示后点击「进入下一 Trial / Episode」。开启减少动画偏好时，跳过飞行动画，保留静态合计数字。
- 历史区保存本 Trial 的全部用药记录，最近一次在上方；结算后保留，进入下一 Trial 时清空。刷新后仅恢复当前 Trial 的记录，完整用药事件仍保留在实验数据导出中。
- 每个 Episode 内 Chemistry 不变，正式场景按固定清单依序加载；药水位置由 seed=0 固定，整个会话保持不变。

## 数据与恢复

自动备份使用 IndexedDB 数据库 `alchemy_human_experiment_v6_6_fixed_eval20`，按事件/Trial/Episode 增量保存，支持完整 200 轮记录并刷新恢复。JSON/CSV 使用 v6.6，新增场景清单 ID、验证 Chemistry ID、验证 Episode seed 和前置约束级别。旧版 localStorage 备份保留，不直接混入新实验。

每轮分数、三块石头各自分数、用药数、原始总价值增量及统一投入事件均记录。结算在动画之前持久化；重复点击、动画中刷新、最后药水反馈中刷新均不会再次加分。未完成时保留本地恢复备份，完成后请下载实验数据。

修改前完整项目已另存于父目录 `_backups/game_before_all_stones_signed_20261024_003511.zip`，详见 `v6.5_修改与核验说明.md`。旧 v6.3 Word 手册和旧版本修改说明保留作历史参考，操作以本 README 和游戏内说明为准。

## 历史查看行为数据

- `history_toggle`：被试主动点击横条时记录展开/收起、时间、Episode/Trial/行动序号、当时可查看的记录数。
- `apply_potion` 和手动 `deposit_all_stones`：`isDecision=true`，`historyClickedBeforeAction` 为当前动作决定前、自上次动作以来是否主动点击历史横条（含主动收起）；同时保存点击次数、展开次数、决定时是否展开、决定前已有记录数。
- 每次决定后重置点击计数，进入下一 Trial 也重置；同一次查看不会被重复计入下一次动作。刷新会保留尚未用于动作统计的点击计数，并将面板收起。
- `history_auto_collapse` 记录用药、手动结算或页面恢复导致的自动收起；不增加被试点击次数。
- 耗尽药水的自动结算不是一次新的动作决定：`isDecision=false`，这些历史决定字段为 `null`，查看情况以最后一次 `apply_potion` 为准。
- JSON 和 CSV 均包含以上事件和字段；完整操作事件继续保留。这些字段记录点击行为，不将点击等同于实际阅读。
- 更新前的旧动作事件不回填点击状态；新动作才写入新增字段。

历史记录展开后，桌面端每行显示两条，按最新到最旧从左到右、从上到下排列。每张卡片上方显示行动次数和原石，下方为药水及石头前后对比；奇数条最后一条保持半行宽度。
